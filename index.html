طريقة التحميل والتشغيل

اتبع الخطوات الخاصة بنظام تلفزيونك. قد تختلف أسماء القوائم قليلًا بحسب إصدار النظام.

Android TV وGoogle TV
  1. نزّل ملف APK من بطاقة Android أعلاه إلى الكمبيوتر أو الهاتف.
  2. انسخه إلى ذاكرة USB، ثم صِلها بالتلفزيون وافتحها بمدير الملفات.
  3. اختر ملف APK واضغط تثبيت. إذا طلب التلفزيون إذنًا، اسمح لمدير الملفات بتثبيت التطبيقات من هذا المصدر.
  4. افتح VUE واتركه في الواجهة؛ بعد دقيقتين من عدم استخدام الريموت تظهر شاشة التوقف المصممة. زر الريموت يعيدك للواجهة.
شاشة VUE تعمل داخل التطبيق المفتوح، ولا تستبدل شاشة التوقف التي يعرضها Android/Google TV عند الخروج إلى تطبيق آخر أو إلى Home. صوت قناة القرآن يحتاج اتصالًا بالإنترنت.

تلفزيونات LG بنظام webOS · خطوات التثبيت

الطريقة السهلة (بدون أوامر)

  1. سجّل حساب مطوّر مجاني في webostv.developer.lge.com.
  2. على التلفزيون: من متجر LG ثبّت تطبيق Developer Mode، سجّل الدخول بنفس الحساب، فعّل Dev Mode Status وأعد تشغيل التلفزيون، ثم فعّل Key Server.
  3. على الكمبيوتر (ويندوز أو ماك): ثبّت برنامج webOS Dev Manager المجاني من صفحة الإصدارات.
  4. في البرنامج أضف التلفزيون بعنوان IP والرمز (Passphrase) الظاهرين في تطبيق Developer Mode.
  5. نزّل حزمة VUE لـ LG واسحبها إلى قسم Apps في البرنامج، ثم شغّل VUE من التلفزيون.

ملاحظة: وضع المطوّر في LG له مدة صلاحية تظهر داخل تطبيق Developer Mode ويجب تمديدها قبل انتهائها، وإلا يتوقف التطبيق المثبّت. التثبيت بدون كمبيوتر يكون فقط بعد نشر VUE في متجر LG الرسمي.

الطريقة المتقدمة (سطر الأوامر)

نسخة LG حزمة واحدة فقط: يفتح VUE الصفحة العامة، ثم ينتقل إلى Sport من الزر داخل التطبيق. لا تثبّت تطبيقًا ثانيًا لـSport. شاشة التوقف تظهر داخل تطبيق VUE. عند الانتقال إلى Home يحتفظ التطبيق بإطار شاشة التوقف حتى يغادر العرض، ويوقف فيديو الخلفية وصوتها.

  1. من متجر LG ثبّت Developer Mode وسجّل الدخول بحساب مطوّر LG. فعّل Developer Mode وKey Server، واتركهما يعملان أثناء التثبيت. إذا ظهر طلب سماح على التلفزيون اختر «نعم».
  2. على الماك أو الكمبيوتر ثبّت Node.js LTS وأدوات webOS CLI:
npm install --global --prefix "$HOME/.webos-cli" @webos-tools/cli
export PATH="$HOME/.webos-cli/bin:$PATH"
  1. عرّف التلفزيون باستخدام عنوان IP الظاهر في إعدادات الشبكة:
ares-setup-device --add vue-tv -i username=prisoner -i host=TV_IP -i port=9922
ares-novacom --device vue-tv --getkey
  1. ثبّت الحزمة الوحيدة وشغّل VUE:
ares-install --device vue-tv ~/Downloads/VUE-LG-webOS-1.58.14.ipk
ares-launch --device vue-tv sa.tlfzyonk.general

لمن سبق وثبّت VUE Sport كتطبيق منفصل، اترك VUE الجديد مفتوحًا ثم أزل المعرّف القديم مرة واحدة:

ares-install --device vue-tv --remove sa.tlfzyonk.home
إذا عرض متصفح التلفزيون «الملف غير مدعوم»، فهذا متوقع: IPK لا يُثبّت من المتصفح. نزّله إلى كمبيوتر ثم ثبّته بأوامر ares-install الموضحة. تحتاج الطريقة إلى Developer Mode. تطبيق webOS لا يستطيع قراءة قائمة Home أو ترتيبها من داخل الصفحة. لمزامنة التطبيقات المثبتة وأيقوناتها استخدم ZIP المرفق على ماك متصل بالتلفزيون عبر SSAP. ترتيب التطبيقات داخل VUE مشترك بين العام وSport، لكنه لا يعيد ترتيب صف Home الأصلي.

تلفزيونات Samsung بنظام Tizen

ملفات Android APK وLG IPK لا تعمل على Samsung. يلزم تجهيز إصدار Tizen منفصل وتوقيعه واختباره على تلفزيون Samsung قبل إتاحة التنزيل. لذلك لا يوجد حاليًا ملف تثبيت لهذا النظام.

  1. بعد تجهيز نسخة Tizen، يلزم تفعيل Developer Mode على التلفزيون وربطه بالكمبيوتر عبر Tizen Studio.
  2. يُثبّت الإصدار للاختبار على التلفزيون من بيئة التطوير. التوزيع العام يكون بعد تجهيز الحزمة واعتماد طريقة النشر المناسبة.
لن يظهر زر تنزيل Samsung حتى تصبح حزمة Tizen جاهزة ومجرّبة؛ لا تستخدم ملفات Android أو webOS على تلفزيون Samsung.

  • على Samsung، يلزم إصدار Tizen مستقل قبل تشغيل شاشة VUE كتطبيق على التلفزيون.
