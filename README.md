# VUE — صفحة التنزيل

صفحة ثابتة بالعربية تعرض حزمة Android TV / Google TV الحالية 1.60.43 وحزمة LG webOS 1.58.23؛ نسخة حديثة واحدة لكل منصة. كل حزمة تجمع العام وSport وKids في تطبيق واحد؛ لا توجد حزمة Samsung Tizen جاهزة.

## معاينة محلية

من هذا المجلد شغّل خادم ملفات ثابتة، ثم افتح العنوان المحلي الذي يظهر:

```sh
python3 -m http.server 8000
```

## النشر

انشر محتويات `dist/` مع `assets/` و`downloads/`. حزم Android وLG منفصلة حسب المنصة؛
